# Instrucciones para ejecutar el proyecto
1. Clonar el repositorio:
   ```
   git clone
    ```
2. Navegar al directorio del proyecto:
   ```
   cd nombre-del-proyecto
   ```
   o mas recomendable abrir en cualquier IDE de preferencia.


3. Abrir el index.html en un navegador web con localhost (si no se usa localhost puede que algunas funcionalidades no funcionen correctamente debido a restricciones de seguridad del navegador).

  
4. La aplicación we debería cargar y mostrar la interfaz de usuario. Puedes interactuar con ella según las funcionalidades implementadas.
